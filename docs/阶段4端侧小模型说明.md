# 阶段 4 端侧小模型组件

本次只实现一条演示链：**无网络 → 本地树新增记忆 → llama.cpp 端侧 Qwen 抽取 → 正常入库**。
记事本、文件分类器和对话应用不作为本轮端侧模型验收场景。

## 组件

- Runtime：官方 `llama.cpp` Android/JNI，固定 gitlink `42e98813e4aba923453d84433c12cfdd29f07a47`。
- ABI：本轮只构建 `x86_64`（Android Emulator），不扩展物理机 ARM 发布包。
- 模型：`Qwen2.5-0.5B-Instruct-GGUF Q4_K_M`，约 6.3 亿参数的亚 1B 轻量模型。
- GGUF 不进入 APK。首次在模型配置页点击“测试端侧模型”时下载到
  `noBackupFilesDir/models/`，并校验固定大小与 SHA-256。
- 在线调用 `CloudModelProvider`；离线调用 `LocalModelProvider`。动态路由发生在每次
  `complete()`，离线状态绝不回退云端 HTTP。

## 构建

1. 初始化第三方源码：`git submodule update --init --depth 1`。
2. Android SDK 安装 NDK `29.0.13113456` 与 CMake `3.31.6`。
3. 在 Android Studio 同步并运行 `app`。模拟器建议 API 35+、x86_64、至少 4 GB RAM。

模型固定信息：

- Revision：`9217f5db79a29953eb74d5343926648285ec7e67`
- 文件：`qwen2.5-0.5b-instruct-q4_k_m.gguf`
- 大小：`491400032` bytes
- SHA-256：`74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db`

## 演示步骤

1. 保持联网，打开控制台抽屉 → 模型设置。
2. 点击“测试端侧模型”。首次会下载、校验、加载 GGUF，并生成一条短回复。
3. 关闭模拟器网络，确认抽屉状态显示离线。
4. 回到本地记忆树，点击 FAB 新增一条记忆。
5. 记忆正常完成结构化抽取并入库；调用日志的模型字段显示
   `端侧小模型（llama.cpp · Qwen2.5-0.5B-Instruct Q4_K_M）`，且不是降级记录。

模型缺失或损坏时会明确提示先准备模型；流水线仍保留原有安全降级入库能力，但不会尝试云端网络。
