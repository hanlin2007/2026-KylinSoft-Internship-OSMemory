# 端侧模型说明

OS Memory 当前只验收一条端侧推理链路：**无网络 → Local Tree 新增记忆 → llama.cpp 端侧 Qwen 抽取 → 正常入库**。备忘录、ChatBot 和文件分类管理器的完整离线推理不在当前验收范围内。

## 组件与边界

- Runtime：仓库通过 Git submodule 固定引入 `llama.cpp`，Android/JNI 封装位于 `llama-runtime/`。
- ABI：当前只构建 `x86_64`，主要面向 Android Emulator。
- 模型：Qwen2.5-0.5B-Instruct-GGUF Q4_K_M。
- 模型文件不进入 Git 或 APK；首次测试端侧模型时下载到应用私有的 `noBackupFilesDir/models/`。
- 每次模型调用都会重新检查网络：在线使用云端 Provider，离线只使用端侧 Provider，不尝试云端 HTTP 兜底。

## 构建准备

1. 初始化第三方源码：`git submodule update --init --depth 1`。
2. 在 Android SDK Manager 中安装 NDK `29.0.13113456` 与 CMake `3.31.6`。
3. 使用 x86_64、API 35 或更高版本且至少 4 GB RAM 的模拟器运行 `app`。

完整的 Android Studio 配置和构建命令见根目录 [`README.md`](../README.md#在-android-studio-中完整运行)。

## 离线验收

1. 保持联网，打开 OS Memory 控制台的模型设置页。
2. 点击“测试端侧模型”，等待下载、校验、加载和短回复完成。
3. 关闭模拟器网络，确认 Cloud Tree 被锁定。
4. 回到 Local Tree，新增一条记忆。
5. 确认端侧模型完成结构化抽取并正常入库，调用日志显示端侧模型通道。

模型缺失、损坏或当前 ABI 不受支持时，系统会给出明确提示。记忆流水线仍保留确定性的降级入库能力，但离线状态不会发起云端模型请求。
