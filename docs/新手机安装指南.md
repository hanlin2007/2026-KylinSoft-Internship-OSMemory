# 新手机 / 新模拟器安装指南

OS Memory 装到一台新设备上需要三样东西：APK、云端 API Key（已内置）、端侧模型文件（自动下载）。
从 v2026-08-08 起，前两项零配置，第三项首次启动自动下载。

## 1. 构建 APK

Android Studio 打开工程 → `Build > Build APK(s)`（或 `assembleDebug`）。

- 模拟器（如 Pixel 9）：端侧推理库仅支持 x86_64（演示目标设备），构建默认即含。
- 真机：端侧模型暂不支持（llama-runtime 只编 x86_64）；云端模型在真机上完全可用，
  离线链路在真机上会显示「当前 ABI 不支持端侧模型」。

## 2. 安装

二选一：

- 数据线 + 开发者模式：`adb install -r app-debug.apk`
- 把 `app-debug.apk` 传到手机（微信/网盘/邮件），直接点击安装（需允许"安装未知来源应用"）。

## 3. 首次启动（自动完成，无需手动操作）

| 组件 | 触发方式 | 说明 |
| --- | --- | --- |
| 云端模型 | 内置 | 2026-08-08 轮换的 API Key 已编译进 APK，联网即用，无需配置 |
| 端侧模型（本地） | 首次启动自动后台下载 | 约 469 MB（Qwen2.5-0.5B Q4_K_M），下载进度见「模型设置」页 |
| 示例数据 | 控制台手动「装载示例数据」 | 演示前点一次即可（离线可用，无需模型） |

端侧模型下载说明：

- 仅在联网且模型缺失时自动触发；下载进度实时显示在 设置 → 模型设置 页面。
- 下载源 huggingface.co，国内网络不可达时自动切换到 hf-mirror.com 镜像（SHA-256 校验一致，安全）。
- 下载完成自动校验（大小 + SHA-256），校验通过前不会启用，避免损坏文件导致推理异常。
- 若自动下载失败（如首次启动时无网络），回到「模型设置」点「测试端侧模型」即可手动重试。

## 4. 新手机验收清单

1. 打开 App → 控制台首页显示「云端大模型（OpenAI 兼容 · deepseek/deepseek-v4-flash）」在线可用；
2. 模型设置页：「端侧小模型」状态从「模型尚未下载」变为「模型已就绪 · 468.6 MB」；
3. 点「测试云端模型」→ 测试成功；点「测试端侧模型」→ 首次会加载 llama.cpp 并生成（真机加载约 10-30 秒）；
4. 断网 → 控制台出现离线锁定提示；发一条记忆 → 端侧完成抽取（离线链路走本地模型）；
5. 装载示例数据 → 画像 / 检索 / 日志各板块正常。

## 5. 常见问题

**云端测试失败（HTTP 401/403）**：确认手机时间正确；若仍失败，在模型设置页手动粘贴新 Key 并保存
（SharedPreferences 里的值优先于内置默认值）。

**端侧测试失败「当前 ABI 不支持端侧模型」**：端侧推理只支持模拟器（x86_64）；真机上属预期行为，演示离线链路请用模拟器。

**端侧测试失败「模型尚未准备」**：自动下载未完成或失败，检查网络后点「测试端侧模型」重试。

**真机推理慢**：Qwen 0.5B Q4_K_M 在 arm64 真机 CPU 推理约 5-15 token/s，用于演示足够；
离线链路只做记忆抽取/整合（短文本），体验尚可。

**旧手机数据迁移**：演示场景建议直接用「装载示例数据」重建，无需迁移。
如需保留旧数据，可导出审计 HTML（含全部记忆 JSON）后在控制台手动重建。

## 6. 演示前 30 秒速查

1. 确认联网，云端可用；
2. 模型设置页确认端侧模型「已就绪」（首次建议提前 10 分钟打开 App 触发下载）；
3. 控制台「装载示例数据」；
4. 断网演示离线链路时，先联网完成一次云端记忆入库，再断网展示端侧抽取/整合。
